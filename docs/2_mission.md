HamSCI's WWV/H Scientific Modulation Working Group is exploring possibilities for additions to WWV and WWVH's modulation that can be used for science purposes. 

**Objective:** Develop recommendations for additions to WWV/WWVH modulation that can be used for scientific purpose.

**Secondary objective:**  Provide regular updates to NIST on PSWS and other efforts using WWV/H as scientific beacons.
